# Week 3  C# Making Decisions

##  Topics Covered

This week, I learned about decision structures and input validation in C# Windows Forms.

### 1. Decision Structures
- `if` statement
- `if-else` statement
- Nested `if` statements
- `if-else-if` statement

### 2. Relational Operators
- Greater than (`>`)
- Less than (`<`)
- Greater than or equal to (`>=`)
- Less than or equal to (`<=`)
- Equal to (`==`)
- Not equal to (`!=`)

### 3. Logical Operators
- AND (`&&`)
- OR (`||`)
- NOT (`!`)

### 4. Boolean Variables
- Using `bool` variables
- Understanding `true` and `false`
- Using Boolean flags

### 5. Comparing Strings
- Using `==` and `!=`
- Using `String.Compare()`

### 6. Input Validation
- Using `int.TryParse()`
- Using `double.TryParse()`
- Checking valid user input

### 7. RadioButtons and CheckBoxes
- Checking selected options
- Using the `Checked` property
- Understanding the `CheckedChanged` event

### 8. Switch Statement
- Using `switch`
- Using `case`, `break`, and `default`

### 9. ListBox Control
- Adding items using `Items.Add()`
- Getting selected items
- Removing items using `Items.Remove()` and `Items.RemoveAt()`
- Clearing items using `Items.Clear()`




##  Learning Objectives

- Understand decision-making statements in C#.
- Use relational and logical operators.
- Compare strings and Boolean values.
- Validate user input using `TryParse()`.
- Work with RadioButtons, CheckBoxes, and ListBoxes.
- Use the `switch` statement to make decisions.

##  Conclusion

In Week 3, I learned how to control program execution using decision structures and how to validate user input in C#. I also practiced using different Windows Forms controls.
